# Smart Logistics Platform

Event-driven microservices platform for delivery management, built with .NET 10,
PostgreSQL, RabbitMQ and React.

> 🚧 Work in progress.

## Stack

.NET 10 · ASP.NET Core · EF Core · PostgreSQL · RabbitMQ · Docker Compose · React + TypeScript

## Getting started

```bash
cp .env.example .env
docker compose up -d
```
